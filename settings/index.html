关于

鲸鱼娘桌宠 v—
  • 左键单击摸摸（随机反应）· 双击开心跳跃 · 按住拖动拎起来移动
  • 右键桌宠或底部信息条 → 菜单（置顶 / 本设置窗口 / 退出）
  • 每笔模型调用到达时，傻鱼会按这笔账的金额轻重受击：轻痛 → 普通痛 → 暴击， 同时在它身上飘出一个「-多少」—— 一笔一个，用多少积分就扣多少，DSH 花的是人民币就飘 ¥
  • 所有插件都只读日志：不写任何文件、不改原插件目录
  • DeepSeek 余额需联网查一次官方接口，Key 只从 DEEPSEEK_API_KEY 或 ~/.dsh/.credentials.yaml 读取，不写盘、不外发
  • 想加自己的数据源：把 providers/_template.js 或目录里 README.md 的示例复制成 xxx.js 放进插件目录，再点「重载插件」，不用重启
数据源
配置文件：config.json（位置 / 大小 / 置顶 / 形象 / 动作开关）、usage.json（插件装没装 / 显示哪些字段）
